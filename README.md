# Albion Hideout Tracker

Public static deployment of the Albion Hideout Tracker, served through GitHub Pages.

## Data privacy

The app saves planner sessions, prices, and settings in the visitor's browser using `localStorage`. It has no account system or shared database. Each visitor's browser profile keeps its own data; visitors cannot read one another's local data through this site.

## Publish

Enable GitHub Pages for the repository and serve the root of the `main` branch. The site entry point is `index.html`.
