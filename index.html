Quick start

  1. Open Database and set the Default target (2,000 to start).
  2. Enter what you currently have in the In Hideout column. Blanks count as 0.
  3. Read the To Buy column. It is MAX(0, Target − In Hideout), so it never goes negative.
  4. Review the To Buy column and estimated restock cost for everything below target.

Targets & overrides

Every row follows the default target. Change the default and all non-overridden rows update.

To give one material a different target, type a number into its Target cell. A small reset arrow appears so you can put it back on the default.

Set a target to 0 for materials you don't stock; their To Buy quantity stays at zero.

Status key

Empty Low Stocked

Empty = none in the hideout. Low = below target. Stocked = at or above target.

The filters above the Stock table can show only Empty, Low, or Below target items.

Adding materials

Use Add material for artifacts, faction materials, or anything else. Type the name, choose a type, tier, and enchantment, and the target / To Buy calculations work the same way. Custom rows can be deleted with the trash button at the end of the row.

This tracker lists refined wood, ore, hide, and fiber only, with the enchantment levels that exist in the live game: T4–T8 run from .0 to .4, while T2–T3 are .0 only. Enchantments are filtered with the All enchants dropdown above the stock table.

Screenshot import

Use Import screenshot above the stock table to read a hideout screenshot. Drop a file, choose one, or paste an image while the dialog is open. The image is processed on this device and is never uploaded.

The importer finds the square slots, then reads the refined material, tier, and enchant from the icon. Items it cannot confidently identify are marked Excluded and left out until you click the X to include them. Check every row before applying. Use the Cell, X, and Y controls if the green boxes do not line up with the slots; Auto-detect restores the automatic grid.

The quantity text in a small screenshot is only a few pixels high, so it is shown in a zoomed crop for you to type. Every included row needs an amount. Replace treats the values as a fresh stocktake for those materials; Add adds them to current stock. Nothing changes until you press Apply to stock.

Craft tab

Open Craft and use the item list on the left: expand a category such as Helmets or Boots, or type in the search box. Click an item to select it. Tier and enchantment buttons narrow the exact recipe, and the crafting costs, return rate, and profit summary update on the right.

The crafting card lists the materials for the quantity you enter. In stock and Short use the quantities from the Stock tab. Artifacts, runes, tokens, and other untracked ingredients are shown with their prices but are not included in the shortage count.

Prices are entered by you. Type a price into an ingredient field or the crafted item's Sell price field. Each value is saved automatically in this browser and reused later for the same item, tier, and enchantment — for example, a price for T6.0 Cloth is reused by every T6.0 cloth recipe. Clearing a field removes the saved price.

Use the inline Return rate slider, or its button for the Royal City + Bonus preset and Hideout + Bonus calculation from the hideout power level and zone quality. Return rate reduces material cost and the profit chart. Best to craft compares every tier and enchantment level using your saved prices. Tiers and enchantments with complete prices are sorted by margin (net profit ÷ investment), highest first. The selected sales tax (6.5% with Premium, 10.5% without) is applied to revenue; click a row to switch the recipe to that tier and enchantment.

Everything works offline. Prices, stock, recipes, and settings are stored locally in your browser.

Tips

  • Add buy prices to see an estimated restock cost. Leave a price blank if you don't want to track it.
  • Use the Stock table filters to focus on Empty, Low, or Below target materials.
  • The Crafting Log is a history only — it does not change stock automatically. Update the Stock tab after a crafting session.
  • Export a backup before clearing browser data or moving this file. Data is stored per browser, not inside the HTML file.
  • Item icons are embedded in the file, so they still appear offline.
  • No account, server, or internet connection is needed. It is a single self-contained HTML file.

Return rate

Resource return lowers the effective material cost. Set a custom rate or use a preset; the value is saved with the tracker.
